# AI総合マスター（G検定＋生成AIパスポート＋AI教養）

G検定の取得対策と、AIを実務で使いこなすための教養学習を統合した、日本語の無料Webアプリです。
ログイン不要・完全無料・学習記録はブラウザ内にのみ保存されます。

## 使い方（学習者向け）

- ホーム：今日の復習、進捗、弱点分野、更新情報
- 教材：分野ごとに基礎解説と詳細解説（推奨順／シラバス順などを切替可能）
- 演習：回答直後に正誤と解説を表示（各選択肢の判定理由は選択肢の下に表示）。問題の全文検索と、問題の保存（★）による絞り込み
- 模擬試験：短縮・分野別・カスタム。タイマー、中断・再開、見直しフラグ付き
  - フル模擬試験は、検証済み問題が公式の145問分そろうまで利用できません（不足を水増ししないため）
- 復習：間隔反復で期限が来た問題を再出題
- 分析：分野別正答率、初見正答率、到達度（合否の保証や合格確率の表示はしません）
- AI教養：教材、実践演習（ルーブリックで自己評価）、モデル比較（各社公式ドキュメントで確認した主なモデル名を確認日付きで掲載）、ニュース
- 設定・更新：表示設定、教材の更新確認、学習記録のエクスポート／読み込み／初期化

教材の更新ボタンの仕組みと、管理者がGitHubで行う更新作業の違いは `docs/UPDATE_GUIDE.md` にあります。

## 開発者向け

```bash
npm install
npm test        # データ検証＋ロジック＋正答の手がかり（作問の偏り）検出の単体テスト
npm run test:e2e  # ビルド＋Playwright E2E（別版のChromiumを使う場合は PW_CHROMIUM_PATH を指定）
npm run build   # 型検査＋本番ビルド
npm run dev     # 開発サーバー
```

- 技術構成：TypeScript / React / Vite、静的アプリ、GitHub Pages想定（相対ベース）
- 設計：UI／学習ロジック／出題／分析／復習／データ／更新／永続化を分離（`src/lib`, `src/data`）
- 開発状況と未達事項：`docs/STATUS.md`
- 公式情報の確認記録：`docs/OFFICIAL_INFO.md`
- シラバス網羅性：`docs/SYLLABUS_COVERAGE.md`

## 注意

- 本アプリの到達度は教育上の参考指標であり、G検定の合否を保証しません。公式の合格点・得点算出方法は公開されていないため、得点換算や合格確率は表示しません。
- 試験制度とシラバスは変更されることがあります。最新の公式情報はJDLA公式サイトで確認してください。
