# UX再設計 — g-ai-master

実施日：2026-11-11／方針：不要なセカンダリラベルや説明を避ける。レイアウト自体に説明させる。

## 1. 情報設計の変更

- **ホーム**：最上部に「次のアクション」を1つだけ置く。優先順位は 模試の再開 ＞ 問題の復習（期限到来）＞ 単語帳の復習（期限到来）＞ 教材の続き ＞ 演習 ＞ 模試／実践。その下に 教材・演習・単語帳・復習・模試（AI教養では実践）の5導線グリッド。到達95%の未達条件はその場で列挙し、免責は最下部のカードに集約した（共通UIルール：説明・免責は下部）。
- **ルーティング**：ハッシュルーティングを導入（#/、#/lessons、#/lesson/<id>、#/practice、#/cards、#/card/<id>、#/exam、#/review、#/analysis、#/literacy、#/settings、#/syllabus）。リロード・直接URL・ブラウザ履歴で画面が復元される（P1-3 の解消）。

## 2. 問題演習の刷新

- **セッションスナップショット方式**：開始時に問題ID列と選択肢の表示順（permutation）を固定し、sessionStorage に保存して再開可能にした。途中でデータや設定が変わってもセッション内の順序は変わらない。
- **同期判定**：回答の記録を同期的な judge に統一し、古い state 参照による競合（P0-3）を排除。
- **シャッフル**：LCG を廃し、mulberry32＋Fisher–Yates に置換（src/lib/random.ts）。問題シャッフル／選択肢シャッフルの ON/OFF と再シャッフルを演習・単語帳で統一し、既定は設定（practicePrefs）に従う。
- **絞り込み**：分野・検索・保存のみ・未回答のみ・直近誤答。問題数は 5／10／20／全件。
- **保存ボタン**：演習・復習の両画面にブックマークを実装（P1-1 の解消）。ブックマークは `q:` / `lesson:` / `card:` の名前空間で単一リストに統合し、旧データ（`q:`、`lesson:`）と互換。

## 3. 模擬試験

- 開始時に選択肢順を ExamSession.choicePerms へ凍結保存（P1-5）。
- フル模試（本番形式：オンライン100分／会場120分）は一時停止なし。短縮・分野別は一時停止可で、strict フラグにより本番条件と区別して記録する。
- 提出は status ガードで二重提出を防止。時間切れは自動提出。
- 結果は提出後にのみ解説を表示し、教材への復習導線を付ける。

## 4. 分析と到達判定（P1-2 の再定義）

到達95%は次の複合条件のすべてを満たす場合にのみ成立する（READINESS_RULES）。

1. 初見ユニーク問題 150問以上
2. 初見正答率 95%以上
3. 初見回答のある章が全体の 80%以上
4. 提出済み模試 3回以上（回答レコード数ではなくセッション単位で再計算）
5. 模試正答率 95%以上

教材の学習済みチェックは条件から除外した（理解の証明ではないため）。未達条件は unmet として全て列挙し、分析画面では 全体／初見／再挑戦 の正答率を分離して表示する（P2-1）。単語帳の自己評価は問題演習の正答率と分離して集計する（P2-2）。

## 5. 教材

- 各教材の先頭に要点カードを配置し、図表（docs/G_AI_CONTENT_VISUAL_AUDIT.md）を本文の流れに沿って差し込む。詳細解説は details に畳む。
- 本文中の重要用語は単語帳カードと対応付け、タップで定義ポップと単語帳への導線を表示（1段落につき最大1用語まで。テキスト過多と誤タップを避ける）。
- AI教養の教材一覧にも検索を追加（P1-4）。教材タブは G／教養で LessonsView を共有する。

## 6. 設定・データ管理

- インポートは厳格検証→プレビュー→明示確認→原子的反映（docs/G_AI_DATA_MIGRATION.md）。
- 読み込み異常時はバナーで退避データのダウンロード・部分復旧・初期化の選択肢を提示し、判断が済むまで自動保存を停止する（protectSave）。
- 初期化の前にはエクスポートを案内する。
