# 単語帳 仕様 — g-ai-master

実施日：2026-11-11／データ：src/data/flashcards.ts／ロジック：src/lib/cards.ts／画面：App.tsx の FlashcardsView

## 1. 目的と位置づけ

問題演習（客観的な正誤判定）とは別に、用語の想起を鍛える暗記専用の導線を新設した。自己評価（覚えた／あいまい／覚えていない）は演習の正答率とは分離して記録・集計し、到達95%判定にも混ぜない。

## 2. データ仕様

- カード型（Flashcard）：id（`card-g01-01` 形式）、mode、syllabusId、conceptId（対応する問題IDと一致させる）、term、aliases?（略称等）、definition、reversePrompt（裏面スタート用の問いかけ）、examples?、pitfalls?、lessonId、questionIds、sources、difficulty、verifiedAt。
- 収録範囲：G検定10章・AI教養7章の全章をカバー（章ごとの枚数は内容量に応じて配分）。
- **答え漏れ防止**：reversePrompt には term と aliases を含めないことを機械検査で担保する（tests/unit/overhaul.test.ts）。表面スタート時は定義文中の用語・略号を App 側で「＿＿＿＿」にマスクして表示する（maskTerm）。

## 3. セッション仕様

- **開始方向**：セッション開始前に「表面（用語）から」「裏面（説明）から」を選ぶ。選択はセッション開始時にスナップショットされ、1枚目からその向きで表示される（途中で既定設定を変えても進行中セッションの向きは変わらない）。既定は設定 cardDirection。
- **範囲**：全件／章別／未学習／苦手（直近の自己評価が「覚えていない」または lapse あり）／期限到来／ブックマークのみ。
- **シャッフル**：ON/OFF と再シャッフル（結果画面からも可能）。乱数は mulberry32＋Fisher–Yates。
- **ブックマーク**：`card:` 名前空間で問題・教材と同じ単一リストに統合。ブックマークのみのセッションを開始できる。
- **自己評価**：裏面を表示した後にだけ「覚えた／あいまい／覚えていない」を選べる（表面のまま評価できない）。評価は間隔反復に反映される。
- **再開**：セッションは sessionStorage に保存され、リロード後も同じ順序・向き・位置から再開できる。
- **一覧ブラウズ**：カード一覧から任意のカードを開き、その位置からセッションを開始できる。

## 4. 間隔反復（src/lib/cards.ts）

問題復習（review.ts）とは独立したパラメータで運用する。

| パラメータ | 値 |
|---|---|
| 初期 ease | 2.5 |
| ease 下限／上限 | 1.3／3.0 |
| 1回目の間隔 | 1日 |
| 2回目の間隔 | 3日 |
| 3回目以降 | 前回間隔 × ease |

- 「覚えた」：間隔を伸ばす。「あいまい」：短めに伸ばす。「覚えていない」：翌日に戻し、ease を下げて lapse を加算する。
- 期限到来（due）と苦手カードはホームの「次のアクション」と分析画面の単語帳統計に反映される。

## 5. 相互リンク

- カード詳細から対応する教材（lessonId）と関連問題（questionIds）へ遷移できる。
- 教材本文中の用語タップから対応カードの定義ポップと単語帳への導線を表示する。
- 演習の結果画面から、その問題に対応するカードへの導線を表示する。

## 6. 検証

- データ整合性（ID一意、参照先の実在、reversePrompt の用語漏れなし、全章カバー）を単体テストで機械検査する。
- ブラウザ実測：両方向の開始で1枚目の表示面が選択どおりであること、再読み込みでセッションが復元されることを Playwright で確認する（証跡は audit-evidence/after/）。
