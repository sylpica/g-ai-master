# 開発仕様（要約）

原典：ユーザーが2026-11-02に提示した「AI総合学習アプリ開発 統合マスタープロンプト」（本開発チャット）。本ファイルは実装判断に必要な確定事項の要約であり、原典が優先する。

## 絶対条件

- 公開先 GitHub Pages／完全無料／日本語／ログイン・有料API・外部DBなし
- モード：G検定取得／AI教養（切替で学習状態を失わない）
- G範囲は最新公式シラバスのみ。問題数に固定目標を置かず、品質と網羅性を優先（水増し禁止）
- 学習記録はブラウザ内保存。教材更新はユーザー操作起点の手動更新
- 到達目標：演習正答率95%以上を複合指標で判定。合格確率や得点換算は表示しない
- UI：レスポンシブ、表示密度変更、アクセシビリティ（WCAG 2.2 AA目標）。不要な説明文で画面を埋めない

## 品質優先順位

正確性 ＞ シラバス・制度への忠実性 ＞ 学習効果 ＞ 実務活用能力 ＞ データ完全性・セキュリティ ＞ UI/UX ＞ 保守性 ＞ 機能数・問題数・速度

## 設計判断（記録）

- 技術構成は原典推奨（TypeScript／React／Vite／Vitest）を採用
- 永続化は当面 localStorage。保存層（src/lib/storage.ts）を分離し、IndexedDBへの移行を可能にした（STATUS.md の未達事項に記録）
- フル模試は問題プール145問到達まで無効化し、不足をアプリ内に明示する（原典6.4）
- 実践演習の評価はルーブリックによる自己評価とし、自動採点と区別して表示する（無料環境で自動採点を偽らない）
- モデル比較では数値を推測で埋めず、観点・確認日・公式リンクを提示する
- GitHub配信は節目バースト（push-files 1回集約、報告に書き込みコール数を明記）の運用ルールに従う
