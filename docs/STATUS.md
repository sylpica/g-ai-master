# 開発状況（2026-11-02 時点）

マスタープロンプトの完成条件（28節）に対する現状。正直に未達を記録する。

## 実装済み

- 2モード切替（G検定／AI教養）。切替後も学習状態は保持される
- 教材：G 10本（全10章）＋教養 7本。基礎／詳細の2段解説、要点、誤解、出典、版・検証日・再検証目安
- 学習順序切替（シラバス順／推奨順／弱点優先／自由）。前提項目の表示
- 問題：54問（G 40問＝全10章×4、教養 14問）。全問に基礎・詳細解説、選択肢ごとの判定理由、出典、検証日を保持
- 演習：即時正誤表示。分野フィルタ
- 模試：短縮（10問）／分野別／カスタム。タイマー、一時停止・再開（中断回数を記録し本番条件と区別）、見直しフラグ、問題一覧、前後移動、途中保存（再読み込みで再開）、提出確認、提出後の解説一括表示
- 復習：間隔反復（SM-2系簡略版、パラメータは `src/lib/review.ts` に明示）。期限到来分をホームと復習画面に表示
- 分析：分野別・初見正答率、模試履歴、到達度（複合条件。単一模試では到達としない。合格確率・得点換算は表示しない）
- AI教養：実践演習6件（ルーブリックによる自己評価。自動採点とは明示的に区別）、モデル比較（観点表。数値は推測で埋めず、日時付き）
- 更新：利用者向け更新確認（マニフェスト取得・形式検証・失敗時は旧データ維持）。管理者向け手順は UPDATE_GUIDE.md
- 設定：テーマ（ライト／ダーク）、文字サイズ、表示密度、モーション抑制。ブラウザ内保存
- 学習記録：自動保存、構造検証付き読み込み、エクスポート、確認付き初期化。外部送信なし
- 自動検証：データ完全性・重複（問題文／選択肢集合の並び替え）・網羅・正答位置偏り検出を含む単体テスト

## 未達事項（完成と判定しない理由）

1. **フル模擬試験が未実装（意図的な制限）**：検証済み問題が40問しかなく、公式145問を構成できない。仕様6.4・28節Bに従い、アプリ内で不足を明示して無効化している。145問以上の独立した検証済み問題が揃うまで完成扱いにしない。
2. 問題数・教材数は網羅の最低条件を満たす段階であり、本試験相当の十分な演習量には達していない。今後、章ごとに問題を拡充する（類似問題の水増しは禁止）。
3. E2Eテスト（Playwright）は未導入。現時点では単体テスト＋ビルド＋手動確認のみ。未検証であることをここに記録する。
4. アクセシビリティはWCAG 2.2 AAを目標に実装上の配慮（フォーカス表示、ラベル、色非依存、モーション抑制、スキップリンク）を行ったが、スクリーンリーダーでの実機確認は未実施。
5. IndexedDBではなく localStorage を使用（保存層は分離済みで移行可能な設計）。大容量化する場合は移行が必要。
