# 公式情報の確認記録（一次情報）

確認日：2026-11-02
第一の情報源：JDLA公式 https://www.jdla.org/certificate/general/ およびシラバス配布ページ https://www.jdla.org/download-category/syllabus/

## 確認済み事項

| 項目 | 内容 | 根拠 |
|---|---|---|
| 適用シラバス | G2024#6以降適用版（旧シラバスはG2024#5まで） | シラバス配布ページの掲載区分 |
| オンライン試験 | 100分／145問程度／知識問題（多肢選択式）／自宅受験 | 公式ページ実施概要表（2026年） |
| 会場試験（Onsite） | 120分／145問程度／知識問題（多肢選択式） | 同上 |
| 変更時点 | 試験時間・出題数の変更はG2026#1より | JDLA 2026年年間スケジュール発表 |
| 受験料 | 一般13,200円（税込）／学生5,500円（税込）※各種割引あり（オンライン） | 公式ページ |
| 受験資格 | 制限なし | 公式ページ |
| シラバス構成 | 技術分野8章＋法律・倫理分野2章＝10章（公式ページ掲載の項目一覧による） | 公式ページのシラバス項目一覧 |

## 注意点（公式ページ内の不整合の扱い）

公式ページには旧制度（120分／160問程度、G2024#6当時の案内）の記述も併存している。適用時期（G2026#1より変更）を比較し、現行制度は「オンライン100分／会場120分・各145問程度」を採用した。古い記述は現行値として使用しない。

## 未確認事項

- 合格点・得点算出方法（公開されていないため、アプリ内で換算・合格確率の表示は行わない）

# 生成AIパスポート（GUGA）の確認記録

確認日：2026-11-11
第一の情報源：GUGA公式 https://guga.or.jp/outline/ および公式シラバスPDF https://guga.or.jp/assets/syllabus.pdf

| 項目 | 内容 | 根拠 |
|---|---|---|
| 適用シラバス | 2027年2月試験より適用版（2026年10月試験までの旧シラバスから章構成を大幅改訂） | シラバスPDF「改訂内容」章別対照表 |
| 試験形式 | オンライン（IBT方式） | 公式試験概要 |
| 試験時間／問題数 | 60分／60問（選択式） | 公式試験概要・FAQ |
| 受験料 | 11,000円（税込）／学生5,500円（税込） | 公式試験概要 |
| 受験資格 | 制限なし | 公式試験概要 |
| シラバス構成 | 第1章 AIの基礎と歴史／第2章 生成AI／第3章 AIエージェント／第4章 生成AIのリスク予防・AI倫理・ガバナンス／第5章 生成AIの実践と活用事例 | シラバスPDF |

## 注意点

- 次回以降の受験は2027年2月試験の新シラバスが対象になるため、本アプリのパスポートモードは新シラバスに準拠する（旧シラバスの「テキスト生成AIのプロンプト制作と実例」中心の構成は採用しない）。
- 合格点・得点算出方法は公開されていないため、G検定と同様に換算・合格確率の表示は行わない。
