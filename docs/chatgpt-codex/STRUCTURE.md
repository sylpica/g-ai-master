## プロンプトの共通パターン（教材化の核）

- 基本型：目的の一文 → 使う入力ファイルの限定列挙 → 番号付きの作業指示 → 成果物の形式・保存先 → 禁止事項（推測で補わない／元ファイルを変更しない／外部送信・予約・購入をしない）。
- 第5章型：まず分析方針と不足情報を示して確認を待つ（いきなり実行しない）。
- 第6章型：方針4点（入力の役割／作業と完成物／不足情報の扱い／停止位置）を示して承認を待つ。
- 第7章型：数値条件を条件ブロックで固定し、確認できない事項は「未確認」として残す。
- 第8章型：Codex＋Gitの操作手順型（記録・差分確認・安全な巻き戻し）。
