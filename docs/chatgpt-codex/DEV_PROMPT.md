# 開発指示：AI総合マスター 第4モード「ChatGPT・Codex」の追加

あなたは学習アプリ「AI総合マスター」（リポジトリ sylpica/g-ai-master、TypeScript／React／Vite、GitHub Pages 公開）の開発担当です。既存の3モード（G検定／生成AIパスポート／AI教養）に、第4モード「ChatGPT・Codex」を追加してください。

## 最初に読むもの（リポジトリ内）

- `docs/chatgpt-codex/REQUIREMENTS.md`（要件の正本。本指示と矛盾する場合は要件を優先し、PRでその旨を報告すること）
- `docs/chatgpt-codex/STRUCTURE.md`（8章56レッスンの構成表）
- `docs/chatgpt-codex/reading-book.md`（書籍の通読メモ：章・レッスンの学習目標、用語集74語）
- `docs/chatgpt-codex/reading-prompts.md`（プロンプト40件の要約と入力ファイル種別）
- `docs/chatgpt-codex/prompts/`（練習用プロンプトの原文40件。演習データの素材。全文転載はしない）
- 既存の実装：`src/types.ts`、`src/App.tsx`、`src/data/`（教材・問題・単語帳・図表の既存データ形式と文体を踏襲すること）

## 実装内容（要約。詳細は REQUIREMENTS.md）

1. モード基盤：Mode に `'chatgpt'` を追加。表示名「ChatGPT・Codex」。教養型（模試・到達度なし）だが教材は標準の lessons ルートを使う。現行 `isExamMode` の分岐は役割ごとに分けて整理し、AI教養モードの既存挙動は変えない。モード切替ボタン（4番目）と設定の起動モード選択肢を追加。保存キーは変更しない。
2. シラバス8件（cx-ch1〜cx-ch8）。
3. 教材56件（les-cx-01〜56）：basic 3段落以上、detail 4段落以上（実践プロンプトの型を具体化する段落を含む）、keyPoints 3点以上、pitfalls 2点以上、図表2点以上、出典必須。書籍の転載ではなく自作の解説として書く。有料版限定機能の教材はその旨を明示。
4. 実践演習40件（Exercise 型）：プロンプトのある40レッスン分を、対応する教材ページの下部に表示する。プロンプト全文の転載はせず、要約を土台に自作する。
5. 演習問題112問（各レッスン2問）：4択、正答・基本／詳細解説・選択肢別理由・出典を完備。正答位置は均等に分散。
6. 図表：各教材2点以上（うち固有のもの最低1点）。既存の lessonVisuals の仕組みを使う。
7. 単語帳90枚：用語集74語（定義は自作）＋章の要点カード16枚。
8. バージョン：contentVersion を 2026.11.16 にし、3点（public/data/manifest.json、src/lib/update.ts、src/lib/storage.ts）を同期。
9. テスト：単体（データ整合性：件数・ID一意性・出典・図表数・問題の完備）と E2E（モード切替、ダッシュボード、教材＋演習表示、演習セッション、単語帳、リロード後の保持、既存モード回帰）を追加し、全テスト通過とビルド成功を確認する。375px幅で新モードの主要画面を確認し、文字の切れ・はみ出し・「実質縦書き」崩れがないこと。

## 恒常ルール（必ず守ること）

- 完全無料（ログイン・有料API・外部DBなし）。得点換算・合格確率は表示しない。
- 問題数・教材数の水増し禁止。56件すべてに固有の内容を持たせる。
- UI：スクロールは最小化し主要コンテンツは一画面に収める。文字の切れ・見切れ・はみ出しを作らない（375px含む）。免責や説明文は画面の下部に置く。図表はラベルと本文を縦積みの箱にし、狭幅では箱ごと折り返す。
- 不要なセカンダリラベルや説明を避ける。レイアウト自体に説明させる。
- 出典URLは実在確認（到達確認）できたものだけを使う。確認できないURLは使わない。
- 既存3モードのコンテンツと学習記録の互換を壊さない。

## 進め方と提出

- 作業は1回のタスクで完結させる前提で、効率よく進めること。途中で利用上限に達しそうな場合は、進捗と残件をリポジトリ内の `docs/chatgpt-codex/PROGRESS.md` に記録してから終えること（次の引き継ぎ先がそのまま再開できるように）。
- 提出はブランチ＋PR（宛先 main）。PR本文に、変更概要、コンテンツ件数の実績、テスト結果（単体・E2E・ビルド）、375px確認の結果、使った書き込みコール数を含めること。
- gh-pages への公開反映は行わない（Muse 側で独立検証後に実施する）。
