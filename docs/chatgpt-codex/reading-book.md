# 『できるChatGPT Work&Codex』通読メモ

対象：書籍PDF全208ページ（目次・各章導入・各レッスン冒頭・各章まとめ・用語集を通読して整理した要約。長文転載はしていない）

## 本書の前提

- 位置づけ：ChatGPTの新機能「ChatGPT Work」（資料整理・文書作成・調査などの仕事を任せられるAIエージェント機能）と、開発向けAIエージェント「Codex」の操作方法を解説する入門書。2026年10月時点の情報をもとに執筆されている（まえがきは2026年10月1日付）。
- 構成：基本編（第1〜3章：基本機能・使い方）と活用編（第4〜8章：実践的な活用とCodexでのバイブコーディング）の2部構成。全56レッスン。各レッスンは実際の画面を使った手順解説形式で、無料の練習用ファイルとYouTube動画が用意されている。
- 対象読者：ChatGPTは使ったことがあるがChatGPT Workは未経験、というビジネスパーソンを中心に想定。仕事だけでなく、家族の予定・献立・旅行など暮らしでの活用も扱う。プログラミング経験は前提にしていない（第8章のアプリ作りもコードを自分で書かずに進める）。
- 前提スキル・環境：Windows 11（25H2）がインストールされ、インターネットに常時接続されたパソコンが前提。ChatGPTのアカウントでサインインして使う。基本操作はデスクトップアプリで行う。
- ChatGPT Work／Codexの位置づけ（事実情報）：
  - ChatGPTのデスクトップアプリでは、目的に応じて Chat（質問応答）／ChatGPT Work（完成物を作る仕事）／Codex（プログラミング）の3モードを使い分ける。WorkとCodexは共通基盤を持ち、操作感覚も近い。
  - ChatGPT Workはデスクトップアプリなら無料で使える。ただし無料版はWeb版では使えず、高性能モデルが利用できず、週間の使用量も低く制限される。
  - プラグイン（外部サービス連携）とスキル（繰り返し作業のパッケージ化）は有料版（ChatGPT Plus）でのみ使用可能。有料版では使用量も増える。
  - 回答例のテキストには検証・編集・改変した箇所が含まれ、同じ質問でも異なる結果が生成されうることが明記されている。
- 読み方：各章の冒頭に登場人物によるイントロダクション、末尾に「この章のまとめ」があり、学ぶ内容と重要ポイントを先に押さえてから手順に入る形式。レッスン内には「使いこなしのヒント」「時短ワザ」「スキルアップ」「用語解説」「ここに注意」などの補助欄がある。

## 章別まとめ

### 第1章 ChatGPT Workとは（基本編、p19〜32）

- 章のテーマ：ChatGPT Workの正体と従来のチャットAIとの違い、利用の始め方、安全に使うための注意点。
- 各レッスンの学習目標：
  - レッスン01 ChatGPT Workって何？：ChatGPT Workが「ひとまとまりの仕事を任せられるAIエージェント機能」であり、デスクトップアプリなら無料で使えることを知る。
  - レッスン02 AIエージェントとは：質問に答える従来のAIと、作業手順を考えて複数ステップを自律的に進めるAIエージェントの違いを理解する。
  - レッスン03 ChatGPT Workでできることを知ろう：Chat／Work／Codexの違いと使い分け、Workで作れる文書・表・プレゼンなどの完成物を把握する。
  - レッスン04 ChatGPT Workのアプリをインストールしよう：Microsoft Storeから提供元がOpenAIの公式アプリを入れ、普段のアカウントでサインインしてWork画面を表示できるようにする。
  - レッスン05 AIエージェントの注意点：コストを意識した使い方、実行の判断は人間が行うこと、利用規約と組織の運用ルールに合わせることを学ぶ。
- 章のまとめの要点：Workは資料を確認しながら複数の作業を進め、完成物を作れるAIエージェント。始める際は自分に合ったプランと公式アプリを確認し、OpenAIの利用規約・ポリシーと所属組織のルールの両方を守って使う。

### 第2章 プロジェクトの効率的な運用を覚えよう（基本編、p33〜54）

- 章のテーマ：画面の役割、資料の読み込み、プロンプト入力、プロジェクト作成、保存先の指定、指示変更、完成物の修正まで、基本操作の一連の流れ。
- 各レッスンの学習目標：
  - レッスン06 ChatGPT Workの基本を身につけよう：作業ごとにプロジェクトを作成し、使う資料を指定して作ってほしい完成物を伝える、という作業の基本形を押さえる。
  - レッスン07 画面の内容を覚えよう：ファイル追加、承認の設定、モデル選択、プロジェクト作成、プラグイン接続など、画面の主要機能の場所と役割を覚える。
  - レッスン08 チャットに入力してみよう：ファイルをアップロードしてプロンプトを入力し、共有用の文書を作らせる基本的な作業の流れを体験する。
  - レッスン09 プロジェクトを作成しよう：案件や目的ごとにプロジェクトを作り、ソースフォルダーを選んで複数の資料をまとめて参照できるようにする。
  - レッスン10 作業するフォルダーを指示しよう：参照するファイルと成果物の保存先フォルダーをプロンプトに明記し、意図しない動作を防ぐ指示の書き方を学ぶ。
  - レッスン11 目的と完成物を組み込んだ指示を書こう：目的・材料・依頼内容・完成物・条件・禁止事項の「プロンプトの6要素」を盛り込んだ具体的な指示が書けるようになる。
  - レッスン12 計画と実行の2ステップで作業を依頼しよう：最初に計画だけを示させ、内容を確認・微調整してから実行させる依頼方法を身につける。
  - レッスン13 ファイルを確認して修正しよう：作成されたファイルを元資料と照合し、誤りと根拠を示させたうえで修正版を作らせる方法を学ぶ。
- 章のまとめの要点：仕事を任せるときは目的・使う資料・完成物・条件・禁止事項を具体的に伝える。作業の計画、許可する操作、生成されたファイルの内容と保存場所は必ず自分でも確認する。

### 第3章 ChatGPT Workに仕事を任せるには（基本編、p55〜68）

- 章のテーマ：任せる作業の範囲や停止位置、使うツールをコントロールしながら、安全に仕事を任せる方法。
- 各レッスンの学習目標：
  - レッスン14 プロンプトを工夫して安全に使う： 「してほしいこと」と「してほしくないこと」の境界を明らかにし、作業内容を確認してから実行させる考え方を学ぶ。
  - レッスン15 操作範囲を指示しよう：使う資料、作成するファイル、禁止フォルダーを具体的に伝え、サンドボックスの範囲内で作業させる方法を学ぶ。
  - レッスン16 複数の作業を並行処理させよう：独立した仕事をサブエージェントに分担させて同時に進め、結果を統合させる指示が出せるようになる。
  - レッスン17 修正前に承認する形にしよう：重要なファイルを書き換える前に停止位置を設定し、変更候補を確認してから実行させる方法を学ぶ。
  - レッスン18 組み込みブラウザーを使ってみよう：組み込みブラウザーでサイトを開かせ、ログインが必要になったら人が操作できる状態で止めるなど、ブラウザー作業の指示と確認の流れを学ぶ。
- 章のまとめの要点：使う資料、保存先、止まる場所、サブエージェントの利用、してはいけない操作を具体的に伝える。ファイルの変更、メールの送信、Webページへのログインなど重要な操作はAIエージェント任せにせず自分で判断・制御する。

### 第4章 プラグインとスキルを使いこなすには（活用編、p69〜82）

- 章のテーマ：有料版で利用できるプラグイン（外部サービス連携）とスキル（作業の自動化）による機能拡張。
- 各レッスンの学習目標：
  - レッスン19 プラグインとスキルとは：プラグインは外部サービスと連携する機能、スキルは繰り返す作業の手順をまとめたもの、という両者の役割とメリットを理解する。
  - レッスン20 ChatGPTをアップグレードするには：有料プラン（ChatGPT Plus）へのアップグレード手順と、無料版の制限（使用量が少なく高性能モデル不可、Web版ではWork不可）を知る。
  - レッスン21 プラグインをインストールするには：Google Calendarのプラグインを例に、インストールとアクセス権限の確認の手順を学び、使わないプラグインを増やし過ぎない運用を意識する。
  - レッスン22 Googleカレンダーの予定を確認するには：プラグインをメニューや「@」指定で選び、確認したい期間と条件を具体的に伝えて予定を調べられるようになる。
  - レッスン23 作業をスキルにするには：一連の作業をスキルとして生成し、内容を確認して、実際にスキルを使って作業できるようになる。
- 章のまとめの要点：プラグインとスキルはChatGPT Workの基本となる重要な機能で、使いこなすとできることが広がり業務効率化につながる。プラグインは目的が決まっているものだけに絞って使うのがポイント。

### 第5章 資料から判断材料を抽出するには（活用編、p83〜106）

- 章のテーマ：会議資料・表計算・報告書・Webページなど複数の資料を見比べ、課題や条件を整理して次の行動の判断材料を作る実践。
- 各レッスンの学習目標：
  - レッスン24 資料から判断を抽出する（導入）：いきなり実行させず、最初に分析方針と不足情報を示させて確認してから進める、というこの章の進め方を押さえる。
  - レッスン25 複数資料から課題と論点を整理するには：会議資料・業務報告・顧客アンケート・案件メモを横断し、根拠を示しながら課題一覧と論点を整理できるようになる。
  - レッスン26 法人情報を公的サイトを使って調べるには：経済産業省のgBizINFOなど情報源を指定し、法人番号で企業を特定して同じ項目で調査レポートを作る方法を学ぶ。
  - レッスン27 社員研修サービスを同じ基準で比較するには：形式の異なる3社のパンフレットを、費用・期間・研修内容・録画・進捗管理という同じ基準の比較表に整理する方法を学ぶ。
  - レッスン28 部門経費の見直すべき点を絞り込むには：3か月分の経費を分類し、異常値と削減候補を特定して翌月予算案まで絞り込む分析の頼み方を学ぶ。
  - レッスン29 防災備蓄が従業員数に合っているか確認するには：人数・備蓄一覧・点検基準を照合して不足を計算し、購入優先順位と保管計画を出させる方法を学ぶ。
  - レッスン30 バラバラな業務メモから遅れと次の優先事項を見つけるには：予定・作業メモ・メール・タスク表を横断して、遅れとリスク、翌週の優先順位を整理する方法を学ぶ。
  - レッスン31 複数案件の優先順位を整理するには：緊急度・価値・依存関係・工数と稼働条件から、複数案件の実行順と週間計画を決める方法を学ぶ。
  - レッスン32 顧客情報から課題仮説を整理するには：公開情報・顧客発言・前回合意・営業側の仮説を区別し、根拠付きの課題仮説と次回商談の質問事項を整理する方法を学ぶ。
  - レッスン33 競合企業の重要な変化を追うには：前回調査時の記録と現在のWeb公開情報を照合し、価格などの差分と通知対象を切り分ける方法を学ぶ。
  - レッスン34 店舗の売上低下の原因を分析するには：POS売上・天候・販促履歴を組み合わせて原因仮説を作り、事実と仮説を分けて改善施策表に整理する方法を学ぶ。
- 章のまとめの要点：ChatGPT Workは複数資料をまとめたり分析したり仮説を考えたりすることが得意。依頼時は使う資料、情報源、比較の基準、出力の形、実行してはいけないことを具体的に指定する。結果はあくまで推測であり、根拠・事実・仮説・不足情報を分けて最終判断は自分で行う。

### 第6章 スライドやダッシュボードを生成するには（活用編、p107〜154）

- 章のテーマ：分析した情報やデータを、テンプレートに沿った資料、ダッシュボードサイト、メール下書き、業務画面への入力など、仕事で使える形に仕上げる生成の実践。
- 各レッスンの学習目標：
  - レッスン35 資料から判断材料を抽出する（導入）：テンプレートの利用、Webからのデータ取り入れ、ループエンジニアリングなど、この章で扱う資料生成の手法の全体像を押さえる。
  - レッスン36 テンプレートどおりに資料を作るには：既存資料とプレゼン資料用テンプレートを基に、形式をそろえた顧客向け資料を作る方法を学ぶ。
  - レッスン37 出店候補地を比較して調査レポートを作るには：RESAS（地域経済分析システム）で3つの候補地の人口などを調べ、比較する調査レポートを作る方法を学ぶ。
  - レッスン38 Googleドライブの資料を使ってGmailの下書きを作るには：Googleドライブ上の会議資料からアクション管理表を作り、担当者別メールをGmailの下書きに保存するまでを連携させる方法を学ぶ。
  - レッスン39 業務データから月次ダッシュボードサイトを作るには：Sitesを使い、対象月や店舗を切り替えて数値と課題を確認できる月次ダッシュボードを作る方法を学ぶ。
  - レッスン40 テンプレートを使って商談メモから提案書を作るには：顧客概要と商談メモを基に、顧客の課題や合意事項を中心に据えた提案書を社内テンプレートで作る方法を学ぶ。
  - レッスン41 アンケート結果から改善報告スライドを作るには：アンケート結果（自由記述含む）を条件に従って分析し、報告用テンプレートに沿った改善報告スライドを作る方法を学ぶ。
  - レッスン42 レシートの写真から経費を入力するには：レシート画像から利用日・支払先・金額を読み取らせ、経費精算サイトへ順番に自動入力させる方法を学ぶ。
  - レッスン43 修了証を集めて研修実績報告書を作るには：Webサイトから対象期間の修了証PDFをダウンロードさせ、研修実績報告書に内容を記入させる流れを学ぶ。
  - レッスン44 撮影計画から機材手配表を作るには：撮影計画書とメンバー予定表、貸出ポータルを照合し、受け取り条件まで考慮した実行可能な機材手配表を作る方法を学ぶ。
  - レッスン45 複数の作業を並行してイベント準備資料を完成するには：作業をサブタスクに分けて並行実行し、品質確認で不合格なら差し戻すループエンジニアリングの流れで資料を完成させる手法を試す。
- 章のまとめの要点：依頼するときは使う資料、完成物の形式、保存先、どこで停止するかを具体的に伝える。最後の確認は人間が責任を持つ。並行処理やループエンジニアリングでは、何を基準にどうループさせるかを自分でよく考えることが重要。

### 第7章 AIエージェントを学びや暮らしに役立てるには（活用編、p155〜182）

- 章のテーマ：家族の予定調整、引っ越し、献立、アルバム、地域イベント、旅行など、日々の暮らしの情報収集と比較・判断への応用。

  - レッスン46 毎日の困りごとを整理して解決しよう（導入）：予定管理、引っ越しの段取り、献立、思い出アルバム、旅行プランなど、仕事以外での活用イメージをつかむ。
  - レッスン47 家族の予定を整理するには：家族の予定リストと習い事の候補・費用・移動時間を組み合わせ、すでに決まっている予定を優先した無理のない組み合わせを作る方法を学ぶ。
  - レッスン48 引っ越し先の物件選びと準備を同時に行うには：物件比較表と手続き一覧を組み合わせ、候補選びから準備の順序までを計画書とチェックリストに整理する方法を学ぶ。
  - レッスン49 冷蔵庫の在庫と給食表から献立を考えるには：在庫表、家族の食事条件、学校給食予定を読み取り、食材を使い切る1週間の献立と買い物リストを作る方法を学ぶ。
  - レッスン50 家族の写真とメモから思い出アルバムを作るには：写真と旅行メモ・日程表を渡し、採用と除外の理由を示させながら見出しと説明付きのアルバムを作る方法を学ぶ。
  - レッスン51 地域イベントを探して1日の予定を作るには：専用サイトで希望条件に合うイベントを絞り込み、開催時間や移動も考慮した1日の行動計画をWordにまとめる方法を学ぶ。
  - レッスン52 プラグインを使って家族旅行の予定を立てるには：trivagoプラグインでホテル情報を取得し、旅行条件ファイルとプロンプトの両方の条件を満たす週末旅行の計画を立てる方法を学ぶ。
- 章のまとめの要点：ChatGPT Workは仕事だけでなく身近な生活シーンでも活用できる。判断に必要な資料の整理や分析はAIエージェントに任せ、自分は家族や仲間との相談に時間を使う。

### 第8章 Codexでバイブコーディングに挑戦するには（活用編、p183〜198）

- 章のテーマ：Codexに対話形式で指示して自分用のWebアプリを作り、改良し、Gitでバージョン管理する「バイブコーディング」の体験。
- 各レッスンの学習目標：
  - レッスン53 アプリ作りに挑戦しよう（導入）：CodexはChatGPT Workと共通基盤・共通の操作体系を持ち、同じ感覚で使えること、この章で作るアプリとGit記録の全体像を押さえる。
  - レッスン54 動画配信サービスの見たい作品をWebアプリでまとめるには：Codexを起動してプロジェクトを作り、配信サービスの作品をカード方式で管理できるWebアプリを言葉の指示だけで構築する方法を学ぶ。
  - レッスン55 Webアプリを改良するには：追加する機能だけでなく引き継ぎたい既存機能も明記して改良を依頼し、完成後に改善版をGitに記録させる方法を学ぶ。
  - レッスン56 アプリのバージョンを戻したり進めたりするには：コミットメッセージを手掛かりにGitの履歴から初版の状態へ一時的に戻し、差分を確認してから改善版へ戻す方法を学ぶ。
- 章のまとめの要点：使う情報源と完成後の動作を伝え、方針を確認してから作成を進める。作成して終わりにせず、必ずGitで状態を記録し、使って気付いた改善点を追加しながら自分用の道具を育てる。
